# Flight Deck typography

Neue Haas Grotesk uses CSS `local()` lookup only, with Arial/system fallbacks. Its proprietary webfont files are not bundled in this repository. Arrow's colors, layout and spacing remain the visual reference. Earlier local copies are retained outside the published assets in the ignored `.sitl/font-recovery_2026_10_11/` directory.

JetBrains Mono Regular is bundled from the official **v2.304** release, together with its copyright and SIL Open Font License 1.1 notice in `OFL.txt`.
