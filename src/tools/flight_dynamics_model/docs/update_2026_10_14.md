# Model and Flight Deck update — 13–14 October 2026

This update brings the flight dynamics model (FDM), the ArduPilot SITL integration and the
Flight Deck in line with PT1 as flown and with PT1.5 as it will be built. It follows a full
audit of the repository, the October aerodynamic database, the PT1 DataFlash logs and the
earlier Aero team correspondence. Engineering results are in
[Flight Dynamics note 0003](../../../../docs/information-note/phase-1/Flight-Dynamics/0003-PT1-5-Hover-and-Fixed-Wing-Assessment/information-note.md).

## What changed and why

### Geometry, mass and CG

| Item | Before | Now | Source |
|---|---|---|---|
| Lift-rotor stations (body x) | +0.55 / −0.85 m, nominal | +0.675 / −0.750 m | 14 October drawing |
| Lift-rotor height (body z) | +0.15 m | −0.043 m | 14 October drawing |
| Rotor centroid x | −0.150 m | −0.0375 m | derived |
| Pusher thrust line | through CG | (−0.374, 0, +0.050) m | drawing x; lowest open mount height |
| PT1.5 CG | (+0.010, 0, +0.150) m, no source | (−0.040, 0, +0.065) m target | CG window analysis |
| PT1 CG | not modelled | (−0.0475, 0, +0.065) m | log17 hover thrust share |

The former rotor rectangle was a placeholder. It also shaped the earlier reading of the PT1
logs: with it, the logged hover thrust share implied a CG at −0.159 m and a large nose
ballast. With the drawing stations the same share gives −0.0475 m.

### Aircraft profiles

- `pt1_as_built` is now **PT1 as flown** in log17: 17.9 kg, wings on, no pusher, servos not
  fitted. Use it for log comparison.
- `pt15` is **PT1.5**: 21 kg build estimate with the pusher. SITL, the Flight Deck and the
  pusher scripts use it. (Earlier, `pt1_as_built` carried PT1.5 values.)
- Both carry build-up inertia and vortex-lattice rate damping. Profiles may now set
  `aerodynamics.rate_derivatives` (`Clp`, `Clr`, `Cmq`, `Cnp`, `Cnr`).

### Aerodynamic reference

- The Aero team confirmed (14 October) that `database.csv` was exported about
  (−0.1, 0, +0.15) m and the deflection tables about (0, 0, 0); the base table is restored
  to (0, 0, 0) before one transfer to the CG. Nondimit applies the 1.3 drag multiplier before
  its moment shift, so the restore is exact; the remaining 0.97 N·m neutral difference is a
  surrogate/run difference, not the multiplier.

### ArduPilot SITL

- Home is the Ankara test field (39.8582, 32.5460, 1125 m above sea level).
- The FDM sends ArduPilot a pitot airspeed consistent with its own density (1.021 kg/m³);
  before, ArduPilot over-read airspeed by about 6.5 % at this altitude.
- The hover-thrust setting includes ArduPilot's air-density motor compensation.
- The FDM sends lift-pack voltage and current (JSON `battery` field). ArduPilot uses them once
  `BATT_MONITOR = 4` is set in SITL, which awaits approval.
- Wind and gusts, and failure injection, apply between the firmware outputs and the physics.
- Transition acceptance uses airspeed when it is recorded.

### Flight Deck

Added: wind and gust inputs, failure injection, live alerts, battery/pusher/elevator/wind
readouts, a CG summary under the CG choice, an Analyze → CG window, and Review → Compare with
aircraft (DataFlash overlay and parameter differences). See
[Flight Deck test tools](flight_deck_test_tools.md).

Removed or simplified: the reference design is no longer offered in the Flight Deck (still
in Model Lab); one transition parameter set remains (9 October proposal); the disabled 3D
view was deleted; "Diagnostic CG" reads "Simulation CG (target, not measured)".

### Solver and housekeeping

- Forward trim tries several elevator starting points; a single start failed between
  solvable neighboring points.
- Generated artifacts, `.DS_Store` files and Python bytecode are no longer tracked.
- Personal absolute paths were removed from reports and docs.

## Migration notes

- Scripts that loaded `pt1_as_built` for PT1.5 should load `pt15`.
- Saved Flight Deck setups using the old CG presets (`forward10`, `legacy`, `forward25`,
  `forward50`) or the removed `pt15` transition parameter set no longer validate; the
  recording still opens. Recordings made with the old rotor geometry are labelled
  "legacy geometry" in Recorded flights.
- The reference design and its fixed-wing SITL configurations remain for software regression
  only: ADB v1.1 is statically unstable at its CG, and those configurations use a CG 0.45 m
  below the origin.

## Verification

- 560 FDM tests pass.
- ArduPlane 4.7.1 SITL at the PT1.5 target CG: hover hold passes; hover → FBWA passes with
  both the earlier and the current parameter sets; hover in 6 m/s wind with a 3 m/s gust
  passes; hover → FBWA into a 6 m/s headwind passes on airspeed; a front-right motor failure
  leaves the attitude envelope 0.4 s after it starts, as expected for a quad-X.
- ArduPilot reads the FDM battery feed (46.6 V, 83 A in hover) with a temporary
  `BATT_MONITOR = 4` overlay.

## Open items

- Aero clarification note 0002: CFD origin location (AQ-01), elevator −20/−30° cases
  (AQ-12) and the speed dependence of the neutral cases (AQ-18) are needed before transition.
- SITL ArduPilot parameter alignment with the aircraft awaits approval (battery monitor and
  failsafe settings, servo ranges, loop rate, voltage compensation).
- PT1.5 must be weighed and ballasted to the target CG; CG z and inertia are estimates.
- Pusher motor (KDE or MAD) and the wooden 20×12 propeller need a static thrust test.
- The SITL still drives virtual elevator/rudder channels; the two-surface V-tail outputs
  (SERVOn_FUNCTION 79/80) are not modelled yet.
